ZAPI Standard Console

Node Navigation Guide — ACE2 Inverter

Important: This guide shows how to navigate between different nodes (Traction, Pump, Steer) using the ZAPI Standard Console connected to ACE2 inverters.
Objective: Learn to switch between truck nodes using the ZAPI Console's CONFIG MENU to access different inverters on the CAN bus network.

Step-by-Step Navigation
1
Connect Console
Physical Connection
Connect the ZAPI Console to the serial port of the ACE2 Inverter, then power on the truck.
2
Console Boot Screen
Initial Display
When switched on, the console displays the program version:
ZAPI
CONSOLE V x.x
Note: V x.x is the console program release number. This appears momentarily.
3
Controller Information
Connected Device
Console shows information about the connected controller:
CONNECTED TO
AE2P2B H NRx.xx
If no alarm is present, you'll see:
AE2P2B H NRx.xx
48V 500A xxxxx
4
Access CONFIG MENU
Button Combination
Press Top Left and Top Right simultaneously to enter the CONFIG MENU:
CONFIG MENU
SET MODEL
5
Enter SET MODEL
Access Node Selection
Press Enter to access SET MODEL:
CONNECTED TO
5
Note: The console shows the node it is currently connected to — typically Node 5 (Pump).
6
Select Desired Node
Navigate Between Nodes
Using Button 5 and Button 6 , scroll between available nodes:
  • Node 2 — Traction (A3MT2C)
  • Node 5 — Pump / Main Lift (AE2P2B)
  • Node 6 — Steer (AC0T2BE)
CONNECTED TO
2
Example: Scrolling to Node 2 will show "CONNECTED TO 2" for the Traction inverter.
7
Confirm Node Selection
Save Connection
Once you have selected the required node, press Out :
ARE YOU SURE ?
YES=ENTER   NO=OUT
Confirmation required: Press Enter to confirm (YES) or Out to cancel (NO).
Press Enter to confirm.
8
Exit and Navigate
Access New Node
The screen returns to SET MODEL. Press Out again to exit CONFIG MENU:
A3MT2C 2NNR x.xx
48V 600A xxxxx
Success! You can now navigate the menus of the selected inverter — in this example, the Traction Inverter (Node 2).
✓

All Steps Completed

You can now navigate between nodes on the ZAPI Console.
Important Notes:
  • Always confirm you're connected to the correct node before making changes
  • Node number corresponds to specific inverters: 2=Traction, 5=Pump, 6=Steer
  • After changing nodes, the console operates as if directly connected to that inverter
  • Some parameters can only be changed on specific nodes
Quick Summary
  1. Connect console to ACE2 serial port
  2. Wait for boot screens
  3. Press Top Left + Top Right for CONFIG MENU
  4. Press Enter to access SET MODEL
  5. Use Buttons 5 & 6 to scroll nodes (2, 5, or 6)
  6. Press Out to confirm selection
  7. Press Enter at confirmation prompt
  8. Press Out to exit and access selected node
