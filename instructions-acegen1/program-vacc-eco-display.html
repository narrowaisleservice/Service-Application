Flexi ACiON Eco Smart Display

Program Traction VACC

⚠️
Important: To program the VACC you will need to connect to the Traction ACE3 Inverter
Programming Procedure
1

Press Enter (Key 3) twice to access the Password Screen

2

Enter your password using Keys 1 to 5

3

Use Key 1 to scroll to ZAPI CONSOLE

4

Press Enter to access the menu

5

Use Key 1 to scroll until you see the connection screen and press Enter (Key 3)

6

Press Key 3 to enter MAIN MENU

7

Use Key 1 to scroll until you see PROGRAMM VACC

8

Press Enter (Key 3) to access PROGRAMM VACC

9

The display will now show you the current values that are programmed for the VACC

10

Press Enter (Key 3) to start the programming

Both Min and Max values will show 0.0

11

Program Forward Direction

  • Select Fwd Direction
  • Push pedal to the floor — you will see the MAX Value change
  • Once all the way down, release the pedal
  • The MAX value will go back to 0.0 — this is fine
12

Program Reverse Direction

  • Now repeat the same process for the Rev Direction
13

Once complete, use Out (Key 2) to exit

14

Press Enter (Key 3) to save the changes

✅ Procedure Complete
