Parameter Range Description
ACCELER. DELAY 0.1s ÷ 25.5s (0.1s steps) Acceleration ramp time: speeds motor from 0 Hz to 100 Hz. Software manages ramp based on speed set point.
RELEASE BRAKING 0.1s ÷ 25.5s (0.1s steps) Deceleration ramp after running request released: time to decelerate from 100 Hz to 0 Hz.
TILLER BRAKING 0.1s ÷ 25.5s (0.1s steps) Deceleration ramp after tiller/seat switch released: time to decelerate from 100 Hz to 0 Hz.
INVERS. BRAKING 0.1s ÷ 25.5s (0.1s steps) Deceleration ramp when direction switch toggled during drive: time from 100 Hz to 0 Hz.
DECEL. BRAKING 0.1s ÷ 25.5s (0.1s steps) Deceleration ramp when accelerator partially released: time from 100 Hz to 0 Hz.
PEDAL BRAKING 0.1s ÷ 25.5s (0.1s steps) Deceleration ramp when braking pedal pressed: time from 100 Hz to 0 Hz.
SPEED LIMIT BRK. 0.1s ÷ 25.5s (0.1s steps) Deceleration ramp on speed-reduction request: time from 100 Hz to 0 Hz.
MAX SPEED FORW 0% ÷ 100% (1% steps) Maximum forward speed as percentage of TOP MAX SPEED.
MAX SPEED BACK 0% ÷ 100% (1% steps) Maximum backward speed as percentage of TOP MAX SPEED.
SMART STOP SPD 10% ÷ 100% (1% steps) Maximum speed when Smart Stop active, as percentage of TOP MAX SPEED.
CUTBACK SPEED 1 10% ÷ 100% (1% steps) Maximum speed when cutback input 1 active, as percentage of TOP MAX SPEED.
FREQUENCY CREEP 0.6 Hz ÷ 25 Hz (0.1 Hz) Minimum speed when direction switch closed but accelerator at minimum.
MAX. CURRENT TRA 0% ÷ 100% (1% steps) Maximum current during acceleration as percentage of factory-calibrated maximum.
MAX. CURRENT BRK 0% ÷ 100% (1% steps) Maximum current during deceleration as percentage of factory-calibrated maximum.
ACC SMOOTH 1 ÷ 5 (0.1 steps) Acceleration profile: 1 = linear ramp, higher values = smoother parabolic profiles.
INV SMOOTH 1 ÷ 5 (0.1 steps) Acceleration profile during direction change: 1 = linear, higher = smoother parabolic.
STOP SMOOTH 3 Hz ÷ 100 Hz (1 Hz) Frequency at which acceleration profile smoothing effect ends.
BRK SMOOTH 1 ÷ 5 (0.1 steps) Deceleration profile: 1 = linear ramp, higher values = smoother parabolic profiles.
STOP BRK SMOOTH 3 Hz ÷ 100 Hz (1 Hz) Frequency at which deceleration profile smoothing effect ends.
AUXILIARY TIME 0s ÷ 10s (0.1s steps) For encoder version: time truck held in place if STOP ON RAMP option is ON.
ROLLING DW SPEED 1 Hz ÷ 50 Hz (1 Hz) Maximum speed for rolling-down function.
