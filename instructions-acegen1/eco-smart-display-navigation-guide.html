ECO Smart Display Navigation

Narrow Aisle Ltd  ·  Complete Navigation & Menu Guide
Keyboard Functions

Overview: The ECO Smart Display uses 5 keys to navigate menus and adjust parameters. Learn each key's function below.

KEY 1
Up / Roll
Scroll UP through menus Roll between parameters Navigate to previous item
KEY 2
Out / Decrease
EXIT current menu DECREASE parameter value Exit without saving
KEY 3
Enter / Select
ENTER selected menu CONFIRM selection EXIT and SAVE changes
KEY 4
Shift / Increase
INCREASE parameter value Shift to next option Modify settings upward
KEY 5
Down / Roll
Scroll DOWN through menus Roll between parameters Navigate to next item

Important: Key 3 (Enter) is used for both entering menus AND saving changes. Key 2 (Out) exits menus and can discard changes.

Quick Reference:
  • Navigation: Keys 1 & 5 (Up/Down)
  • Selection: Key 3 (Enter)
  • Value Adjustment: Keys 2 & 4 (Out/Shift)
  • Exit: Key 2 (Out) or Key 3 (with save)
Inverter Nodes — CAN Bus

Connection: After accessing ZAPI CONSOLE from the SERVICE MENU, you can connect to individual inverters on the CAN bus network. Each inverter controls different truck functions.

DISP EDZ NRx.xx
ECO Smart Display itself — display configuration and settings
Display
A3MT2C 2NNRx.xx
Traction inverter — controls drive motor, forward/reverse, speed control
Traction
A3ST2C 2NNRx.xx
Traction Slave — used to check alarms of the slave processor only
Traction Slave
AE2PSB H NRx.xx
Pump inverter — controls main lift hydraulic pump, lift/lower functions
Pump (Lift)
AC0T2BE NRx.xx
Pump inverter — controls steering hydraulic pump, steer motor
Pump (Steer)

Note: The x.xx in each inverter name represents the software version level. This will vary depending on the installed firmware.

Once Connected: The display functions exactly like a ZAPI digital console. You can access all parameters, diagnostics, and programming functions for that specific inverter.

Menu Structure & Navigation

Menu Overview: Once connected to an inverter, you can navigate through different menu categories. The main screen provides access to all functions.

Main Screen — Connected Inverter
Key 3 — Enter Press ENTER to access:
Parameters — view and modify parameters
Set Options — configure operational settings
Adjustments — fine-tune system adjustments
Key 1 — Up Press UP to access:
Diagnostics — system diagnostics and troubleshooting
Alarms — view active and historical alarms
Monitoring — real-time system monitoring
Key 2 — Out Press OUT to:
Return to main screen
Exit current menu level
Navigation Rules:
  • Enter (Key 3) — Go deeper into menus
  • Out (Key 2) — Go back to previous level
  • Up/Down (Keys 1 & 5) — Navigate between menu items
Parameter Menu Guide

Important: This procedure applies to PARAMETERS, SET OPTIONS, and ADJUSTMENTS menus. All three use the same navigation method.

Step-by-Step Parameter Editing
01
Access Parameter Menu
Press Key 3 (Enter) to access the Parameter menu
02
View First Parameter
Display shows the first parameter in the list with its current value
Parameter Name: XXX
Current Value: YYY
03
Navigate Through Parameters
Use Key 1 (Up) and Key 5 (Down) to scroll through the parameter list
04
Adjust Parameter Value
Use Key 2 (Out) to Decrease — use Key 4 (Shift) to Increase

Tip: Watch the display as values change in real-time.

05
Exit Parameter Menu
Once finished, press Key 3 (Enter) to exit the parameter menu
06
Save or Discard Changes
You will be prompted to save:
Key 3 Exit & Save Changes
Key 2 Exit & Ignore Changes

Critical Warning: Changes are NOT automatically saved. You MUST press Key 3 when prompted to save parameter changes. Pressing Key 2 will discard all changes made in that session.

Quick Parameter Change Flow
Enter Menu Key 3
→
Scroll to Parameter Keys 1/5
Adjust Value Keys 2/4
→
Exit Key 3
Save Key 3 or Discard Key 2
→
Complete
Remember:
  • Keys 1 & 5 — Navigate between parameters
  • Keys 2 & 4 — Decrease / Increase values
  • Key 3 — Enter menus and SAVE changes
  • Key 2 — Exit and potentially DISCARD changes
