Software Configuration  /  ACE3: NR070  /  Display: NR016

ACiON Hour Meter Update

Narrow Aisle Ltd  ·  ECO Smart Display Hour Meter Transfer

Critical Warning: If Display has version NR0.14, the truck will have a DRIVE FAULT. Ensure the correct software version (NR016) is installed before proceeding.

Overview: This procedure changes the functionality of the displayed hour meter by loading the hour meter value from the ECO Smart Display into the ACE3 controller. Follow all configuration steps and the loading procedure in exact order.

ACE3 Configuration Options
Config 01
HM DISPLAY OPT = LEVEL 3
LOAD HOUR METER FROM ECO Turn ON if you want to load hours from the ECO Smart Display — same functionality as the former LOAD HM FROM MDI setting.
ECO Display Configuration
Config 02
HOUR COUNTER = OPTION #3 — displays the Hour Meter from ACE3
ACE3 Tester Menu — Hour Counters
Reference
HM DISPLAY OPT Seat Hours
HM DISPLAY OPT #1 Key On Hours
HM DISPLAY OPT #2 Traction Running Hours
Procedure Progress 0 / 12 steps

Load Procedure: Follow the steps below in exact order to load the hour meter from ECO Smart Display.

01
Disconnect Display
Preparation
Pending

Disconnect the display you want to load the hour meter from.

Note: If the display is not connected, skip this step.

02
Turn On Truck
Power Up System
Pending

Turn on the truck to power up the system.

03
Connect to ACE3 Master
Controller Connection
Pending

Establish connection to the ACE3 Master controller using your diagnostic tool.

04
Navigate to Options Menu
Menu Access
Pending

Go to the Options Menu in the ACE3 Master interface.

05
Configure Load Parameter
Critical Setting
Pending

Set LOAD HM FROM ECO to ON and press Store

Important: At the next key cycle, the controller will load into its own hour meter the value stored in the MDI CAN. The parameter will automatically restore to OFF after transfer — this is expected behaviour. Use this to match the controller hour meter after controller replacement.

06
Turn Off Machine
Power Down
Pending

Turn off the machine completely.

Note: Wait for all systems to power down completely before proceeding.

07
Reconnect Display
Hardware Connection
Pending

Re-connect the display to the system. Ensure all connections are secure before powering on.

08
Turn On Machine
Power Up for Transfer
Pending

Turn on the machine. The hour meter will automatically load from ECO to the controller during this power-up cycle.

09
Verify Hour Meter Transfer
Confirmation
Pending

Hour meter will be loaded from ECO to controller.

Verify: Check that the hour meter reading on the display matches the expected value from the ECO Smart Display.

10
Verify Parameter Reset
Auto-Reset Confirmation
Pending

Verify that LOAD HM FROM ECO has automatically reset to OFF

Note: This automatic reset confirms the transfer completed successfully.

11
Test All Functions
Operational Check
Pending

Perform operational tests to ensure:

  • · Hour meter displays correctly
  • · No drive faults present
  • · All systems functioning normally
  • · Display showing proper readings
12
Document Update
Record Keeping
Pending

Document the hour meter update in service records:

  • · Date and time of update
  • · Previous hour meter reading
  • · New hour meter reading
  • · Technician name
  • · Any issues encountered
✓

Hour Meter Update Complete

All steps completed. Hour meter has been successfully loaded from ECO Smart Display. Ensure changes are documented in service records.

Important Reminders:
  • Ensure Display version is NR016 — NR0.14 will cause drive faults
  • ACE3 software should be NR070
  • LOAD HM FROM ECO automatically resets to OFF after successful transfer
  • Always document hour meter changes in service records
  • Verify no drive faults after completing procedure
  • This procedure is typically used after controller replacement
