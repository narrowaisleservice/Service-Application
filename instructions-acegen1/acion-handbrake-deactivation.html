Configuration Procedure  /  AC3MT2C Inverter

ACiON Handbrake Deactivation

Narrow Aisle Ltd  ·  Handbrake Time Parameter  ·  Display 15251

Critical: This procedure modifies handbrake operation. Only perform if authorised and necessary. Always conduct an operational test after completion.

Objective: Deactivate the handbrake delay time by setting the parameter from 4.0 seconds to 0 on the AC3MT2C inverter via Display 15251.

Procedure Progress 0 / 8 steps
01
Enter Display
Initial Access
Pending

Power on the system and access Display 15251

Note: Ensure the display is showing the main menu before proceeding.

02
Select ZAPI Console
Menu Navigation
Pending

Navigate to and select ZAPI Console on the display

Use the navigation buttons to scroll through menu options until you reach the ZAPI Console option.

03
Navigate to AC3MT2C Inverter
Inverter Selection
Pending

Scroll down through the menu until you see AC3MT2C Inverter

Important: Make sure you select the correct inverter. The AC3MT2C is the traction inverter.

04
Enter Parameter Change Mode
Access Configuration
Pending
  • 1 Press Enter to select the inverter
  • 2 Press Enter again until you see Parameter Change displayed on screen

Tip: You may need to press ENTER multiple times to cycle through menu options until Parameter Change appears.

05
Access Parameter List
Enter Configuration Menu
Pending

Press Enter on Parameter Change

This will open the list of configurable parameters.

06
Locate Handbrake Time
Find Target Parameter
Pending

Scroll down through the parameter list until you see Handbrake Time

Current display value:

4.0

Press the Left Button repeatedly to reduce the value from 4.0 to 0

Action Required: Keep pressing the left button until the display shows 0.0

07
Save Changes
Confirm Configuration
Pending

Once the value reads 0 press the Middle Button

  • 1 The display will show "Are you sure?"
  • 2 Press Middle Button again to confirm YES

Critical: This saves the new parameter value to memory. Do not power off until confirmation is shown.

08
Cycle Key & Test
Final Verification
Pending

Power Cycle:

  • 1 Turn the key OFF
  • 2 Wait 5 seconds
  • 3 Turn the key back ON

Operational Test Required:

  • Test handbrake operation in a safe area
  • Verify immediate response (no 4-second delay)
  • Check all safety systems function correctly
  • Document test results in service log
✓

Procedure Complete

Handbrake time parameter successfully set to 0. Ensure operational test has been documented in service records.

Important Notes:
  • Only authorised personnel should perform this procedure
  • Ensure vehicle is in a safe location before starting
  • Document all parameter changes in service records
  • Setting handbrake time to 0 removes the delay completely
  • If issues occur, restore parameter to 4.0 and contact technical support
