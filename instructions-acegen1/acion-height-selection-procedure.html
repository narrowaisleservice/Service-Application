ACiON Height Selection Procedure

Narrow Aisle Ltd  ·  Laser Positioning System  ·  Up to 12 Height Positions

Critical: The teaching procedure MUST be carried out in the order specified below. Failure to follow the correct sequence will cause the lifting function and height selection to fail.

Overview: This procedure configures the laser height selection system, allowing up to 12 programmable height positions. Heights can be grouped — for example, Heights 1–6 for Warehouse A and Heights 7–12 for Warehouse B.

Required Equipment:
  • Zapi Smart Console
  • Measuring tape or laser distance meter
  • Access to AE2PBH Node 5 "PUMP"
Quick Reference — Parameter Summary
Parameter Setting
HEIGHT SELECTION ON
OPT. HEIGHT #1–12 ON (as required)
LIFT HEIGHT CTB 20%
LIFT HEIGHT S.D 0.5V
Phase 01 Set Laser — Initial Measurement
▼
Measure Distance X
X = _______ mm
From front (glass) face of sensor to target — mast in LOWERED POSITION
01
Position mast in the fully lowered position
02
Measure the distance from the sensor glass face to the target reflector
03
Record this as Distance 'X' — this is your baseline measurement

Sensor Setup: Ensure the laser sensor is properly mounted and aligned. The glass face should be clean and the target reflector properly positioned on the mast.

Phase 02 Height Selection Menu Options
▼

Using Zapi Smart Console — AE2PBH Node 5 "PUMP"

01
Connect Zapi Smart Console and access AE2PBH Node 5 "PUMP"
02
Scroll to Menu Options and press Enter
03
Scroll to Height Selection — set to ON
04
Scroll to OPT. HEIGHT #1 — set to ON
05
If more heights are required, enable additional heights:
OPT. HEIGHT #2 → ON
OPT. HEIGHT #3 → ON
... continue up to ...
OPT. HEIGHT #12 → ON

Maximum Heights: Up to 12 heights can be selected. Enable only the heights needed — e.g. 1–6 for Warehouse A, 7–12 for Warehouse B.

06
When all required heights are selected:
Press ESC Press OK Re-cycle the key to store settings
Phase 03 Adjustment — Teaching Procedure
▼
01
Scroll to Menu Adjustment and press Enter
02
Scroll to Lift Height #1
03
Raise forks to the first height position required

Note: You will see the laser value change as the forks are raised. Position the forks at the desired height before pressing OK.

04
When forks are at the correct height, press OK — this teaches Height #1
05
If more heights are required, repeat for each:
Scroll to Lift Height #2 → Raise forks → Press OK
Scroll to Lift Height #3 → Raise forks → Press OK
... continue up to Height #12 ...
06
When all height positions are taught:
Press ESC Press OK

Critical: Each height must be taught in sequence. Do not skip heights or teach out of order — this will cause lifting function and height selection to fail.

Phase 04 Final Parameters & Testing
▼
01
Scroll to Parameters Menu and press Enter
02
Set the following parameters:
LIFT HEIGHT CTB Scroll to parameter and set to 20%
LIFT HEIGHT S.D Scroll to parameter and set to 0.5V
03
After setting parameters:
Press ESC Press OK Re-cycle the key to store all settings
04
Run and test all selected heights
Operational Test Required:
  • Test each programmed height position
  • Verify forks stop at correct heights
  • Check laser sensor is reading correctly
  • Ensure smooth operation without errors
  • Document all heights in service log
Critical Notes:
  1. Teaching procedure MUST be carried out in the order specified. Incorrect sequence will cause lifting function and height select to fail.
  2. Heights can be grouped as required — e.g. Heights 1–6 for Warehouse A, Heights 7–12 for Warehouse B.
  3. Always re-cycle the key after making changes to store settings in memory.
  4. Perform thorough operational testing after setup is complete.
